# Le deck Commander que tu as déjà presque

Post « fonction » : les decks les plus joués comparés à ta collection (cartes possédées, à acheter, prix), les trois budgets, puis le Coach (note, catégories, bracket, échanges).

**Images** : 01.jpg, 02.jpg, 03.jpg, 04.jpg, 05.jpg, 06.jpg (1080 × 1350, dans cet ordre)

## Légende

```
Il y a de bonnes chances que t'aies déjà les deux tiers d'un deck Commander qui dort dans tes classeurs.

L'appli compare ta collection aux listes les plus jouées pour chaque commandant, et te sort ce qu'il te manque avec le prix. C'est comme ça qu'on découvre qu'un Edgar Markov qu'on croyait hors de prix ne demande plus que dix cartes.

Et pour les decks que t'as déjà, le Coach donne une note et dit où ça coince.

#commander #edh #mtg #mtgfrance #edhdeck
```

## Texte alternatif

Pour chaque image : « Paramètres avancés › Accessibilité › Écrire un texte alternatif » (lu aux personnes malvoyantes, et aide Instagram à comprendre le post).

1. Couverture : « Le deck que tu as déjà presque », téléphone ouvert sur les idées de decks de Mana Orbit.
2. Les decks Edgar Markov avec le nombre de cartes possédées et le prix de celles à acheter.
3. La liste d'un deck avec sa valeur et le total à acheter.
4. Trois budgets pour un même commandant : budget, moyen, premium.
5. Le Coach : une note sur 100, les catégories qui manquent, le bracket estimé, des échanges conseillés.
6. Fin : logo Mana Orbit, gratuite sur Google Play, manaorbit.app.
