# Devine la carte en 5 indices

Post « jeu » : un indice par diapo, la réponse à la fin, les gens commentent à quel indice ils ont trouvé. Se termine sur la Carte mystère de 18 h dans l'appli. Format à refaire avec d'autres cartes.

## Légende

```
Petit jeu. Une carte, cinq indices, et tu t'arrêtes dès que tu penses l'avoir.

Celle-là est facile pour les joueurs de Commander, je sais. Les prochaines seront moins gentilles.

Si t'aimes ce genre de truc, il y a une Carte mystère tous les soirs à 18 h dans l'appli, avec un classement.
```
